# AlgoCube

Android WebView wrapper generated from a single HTML file.

## Build the APK for free

1. Push this folder to a GitHub repository (include the `.github` folder).
2. Open the **Actions** tab and run **Build APK** if it has not started.
3. Download the `apk` artifact from the finished run.

## Change the app later

Edit `app/src/main/assets/www/index.html`, commit, and the workflow builds a new APK.
